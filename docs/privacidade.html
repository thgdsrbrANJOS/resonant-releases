Política de Privacidade

RESONANT · Última atualização: 23 de outubro de 2026 · English version below · Página inicial

1. Quem somos

O RESONANT é um programa para Windows desenvolvido por Thiago Anjos (thgdsrbr@gmail.com). Ele roda no computador do espectrômetro de RMN do laboratório e registra as análises feitas no equipamento.

2. O desenvolvedor não recebe os seus dados

O RESONANT não tem servidor próprio, não envia dados ao desenvolvedor e não usa ferramentas de estatística ou publicidade. Tudo o que o programa registra fica no computador do laboratório e na conta Google que o próprio laboratório conectar.

3. Quais dados o programa usa

  • Operadores: nome, e-mail e senha de cada operador, cadastrados pelo laboratório. As senhas são guardadas apenas como hash (não é possível recuperá-las).
  • Análises: data, nome da amostra, experimento, núcleo, pulso, solvente, instituição, solicitante e caminho da pasta, lidos dos arquivos do TopSpin/IconNMR.
  • Licença: um ID de hardware calculado no próprio computador. Ele só sai do computador se o laboratório o enviar ao desenvolvedor para pedir uma licença.

4. Uso da conta Google

Quando o laboratório clica em Conectar com Google, o RESONANT pede apenas estas permissões:

  • drive.file — ver, criar e editar apenas os arquivos criados pelo próprio RESONANT: a planilha de análises e os arquivos de backup, guardados na pasta “RESONANT” do Google Drive da conta. O programa não consegue ver nem alterar nenhum outro arquivo do Drive.
  • openid e email — mostrar no programa qual conta está conectada.

Esses dados são usados somente para gravar as análises na planilha do laboratório e para fazer e restaurar os backups. Eles não são vendidos, compartilhados com terceiros nem usados para publicidade ou para treinar modelos de inteligência artificial.

O uso e a transferência de informações recebidas das APIs do Google pelo RESONANT seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Onde os dados ficam

  • No computador do laboratório, na pasta %LOCALAPPDATA%\RMNSystemConfig.
  • A autorização da conta Google (token) fica nesse mesmo computador, criptografada pelo Windows, e só pode ser aberta pelo usuário do Windows que fez a conexão.
  • A planilha e os backups ficam no Google Drive da conta do laboratório, sob controle exclusivo do laboratório.

6. Atualizações

O RESONANT consulta periodicamente a página de versões no GitHub para saber se há uma atualização. Nessa consulta nenhum dado do laboratório é enviado; o GitHub pode registrar o endereço IP de acordo com a política de privacidade dele.

7. Como remover o acesso e apagar os dados

  • Desconectar a conta: no RESONANT, em Configurações > Desconectar, ou em myaccount.google.com/permissions.
  • A planilha e os backups podem ser apagados a qualquer momento no Google Drive da conta.
  • Os dados locais podem ser apagados excluindo a pasta %LOCALAPPDATA%\RMNSystemConfig depois de desinstalar o programa.

8. Contato

Dúvidas sobre esta política: thgdsrbr@gmail.com.

Privacy Policy (English)

Last updated: October 23, 2026

Who we are. RESONANT is a Windows program developed by Thiago Anjos (thgdsrbr@gmail.com). It runs on the laboratory's NMR spectrometer computer and logs the analyses run on the instrument.

The developer does not receive your data. RESONANT has no server of its own, sends no data to the developer and uses no analytics or advertising tools. Everything it records stays on the lab's computer and in the Google account the lab connects.

Data used. Operators' names, emails and passwords (stored only as hashes); analysis details read from TopSpin/IconNMR files (date, sample, experiment, nucleus, pulse program, solvent, institution, requester, folder path); and a hardware ID computed locally for licensing, which leaves the computer only if the lab sends it to request a license.

Google account. When the lab clicks Connect with Google, RESONANT requests only: drive.file — see, create and edit only the files RESONANT itself creates (the analysis spreadsheet and backup files, kept in the “RESONANT” folder of that account's Google Drive); it cannot see or change any other Drive file; and openid/email — to show which account is connected. This data is used only to write the analyses to the lab's spreadsheet and to create and restore backups. It is not sold, shared with third parties, or used for advertising or to train AI models.

RESONANT's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Where data is stored. On the lab's computer (%LOCALAPPDATA%\RMNSystemConfig); the Google authorization token is stored on that computer, encrypted by Windows for the Windows user who connected; the spreadsheet and backups live in the lab's own Google Drive, under the lab's control.

Updates. RESONANT periodically checks the GitHub releases page for updates. No lab data is sent; GitHub may log the IP address under its own privacy policy.

Removing access and deleting data. Disconnect in RESONANT (Settings > Disconnect) or at myaccount.google.com/permissions; delete the spreadsheet and backups in Google Drive at any time; delete local data by removing %LOCALAPPDATA%\RMNSystemConfig after uninstalling.
